WHOIS查询 - 在线域名信息查询工具 | 挽着红月缓缓走
WHOIS 查询 · 挽着红月缓缓走

接口文档

接口概述

本 API 提供域名 WHOIS 信息查询服务，支持输入完整 URL 或纯域名，自动提取主域名并进行 RDAP 查询，RDAP 不可用时自动回退至 WHOIS。

参数说明
地址GET https://whoiscx.delishahk.com/api/
参数whois — 域名或完整 URL（必填）
响应application/json / UTF-8

速率限制

  • 每 10 秒 内最多 20 次请求
  • 超限返回 HTTP 429
  • 基于客户端 IP 地址

错误码

状态码说明
400缺少参数或域名格式无效
404路径非 '/api/'
405请求方法不是 GET
429请求频率超限
500查询 RDAP 失败或内部错误

请求示例

curl "https://whoiscx.delishahk.com/api/?whois=example.com"

页面路径直传

页面支持将待查询内容直接拼在路径后面，页面加载后会自动识别并发起查询：

  • 纯域名：https://whoiscx.delishahk.com/example.com
  • 完整 URL：https://whoiscx.delishahk.com/https://www.example.com/path

提示：把 HTML 部署到子目录时，需要相应设置 DEPLOY_BASE 常量（见页面 JS 顶部）；同时服务器需配置 SPA 回退，把所有非静态路径都指向 index.html。

  • 缓存：12 小时（Cache-Control: max-age=43200）
  • 基于 RDAP 协议，不可用时自动回退 WHOIS
  • 部分信息可能受隐私保护或脱敏

帮助与问题

常见问题

如何查询域名？

在搜索框中输入完整的网址（如 https://example.com/path）或纯域名（如 example.com），然后点击「查询」按钮即可获取该域名的 WHOIS 信息。

API 如何调用？

请点击左上角的三横杠图标打开侧边栏，里面有完整的 API 接口说明、请求示例和错误码定义。

此 API 的性质是什么？

该 API 是一个免费的 RDAP 查询 API，RDAP 不可用时自动回退至 WHOIS。请勿批量刷取请求，目前限制为每 10 秒最多 20 次请求，超限将返回 429 状态码。

如何分享查询结果？

查询完成后，页面右下角会出现「分享截图」按钮。点击后会截取从查询框到结果卡片的区域，并尝试调用系统分享；若设备不支持，会自动下载 PNG 图片到本地。也可以直接复制地址栏 URL，路径中会保留查询目标。
