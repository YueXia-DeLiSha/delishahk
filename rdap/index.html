RDAPWHOISAPI角色扮演科普

用崩坏三双人对话，带你轻松搞懂RDAP与我的免费域名查询AP

2026-09-05T08:35:19.000Z1.3k

(场景：休伯利安号的休息室。雷电芽衣正在料理台前准备着晚餐，空气中弥漫着浓郁的炖汤香气。琪亚娜趴在餐桌上，手里划动着平板电脑，像只等待投喂的小猫一样晃着腿。)

琪亚娜：“芽衣芽衣！好香啊，本小姐的肚子已经咕咕叫了！对了，你快来看看我发现了什么好东西！为了帮德丽莎查那个新活动域名的有效期，我本来想找个 WHOIS 查询工具的，结果发现现有的工具总觉得‘差点意思’。然后我就顺藤摸瓜，发现了一个博主自己搭建的超厉害的 RDAP 查询 API 哦！”

芽衣：(放下手中的汤勺，温柔地擦了擦手，转过身轻笑) “慢点说，琪亚娜，先喝口汤垫垫肚子。不过，在说你的‘超厉害’之前，琪亚娜真的清楚什么是 WHOIS 和 RDAP 吗？知道它们的作用？”

琪亚娜：(捧着汤碗喝了一口，眼睛亮晶晶的) “唔……WHOIS 嘛，本小姐当然知道！就像是域名的‘户口本’！用来查域名什么时候到期、是谁注册的！至于 RDAP……嘿嘿，虽然本小姐不太懂那些复杂的代码，但我知道它是 WHOIS 的超级进化版！对不对？”

芽衣：(无奈又宠溺地笑了笑，拿纸巾擦去琪亚娜嘴角的汤渍) “算你聪明。简单来说，WHOIS 确实是最早用来查询域名注册信息的古老协议。但因为它年代太久远，存在不支持多语言、数据格式不统一、隐私保护差等很多缺点。
而 RDAP（Registration Data Access Protocol，注册数据访问协议），就是 ICANN 为了替代 WHOIS 推出的新标准。它基于 HTTP 和 JSON 格式，数据结构更清晰，查询结果也更标准化、更安全。现在越来越多的服务都在向 RDAP 过渡了。”

琪亚娜：“对对对！那个写博客的 挽着红月缓缓走 博主也是这么说的！他说他给 AI 布置查询域名信息的任务时，觉得老工具不好用，就决定自己动手搭一个！而且哦，他找项目的时候，专门找支持‘无服务器部署’的！”

芽衣：“无服务器部署？是因为这样可以节省服务器的成本吗？”

琪亚娜：(得意地叉腰，理直气壮地说) “嘿嘿，博主说了，他选无服务器部署，绝对不是因为没钱！就像本小姐买限量版手办绝对不是因为零花钱不够一样！他选了 Cloudflare Workers 作为运行底座，实现了高缓存和高可用，保证每次调用有 99% 的可用率呢！”

芽衣：(被琪亚娜的比喻逗笑了，轻轻揉了揉她的白发) “是是是，琪亚娜的零花钱都变成手办了。不过，为什么是 99% 的可用率，而不是 100% 呢？”

琪亚娜：“(吐了吐舌头) 因为 Cloudflare Workers 的免费版套餐有调用次数限制呀！博主还特意祈祷不要被恶意刷取呢。不过放心啦，这个 API 是公益免费的，完全不收费哦！介绍页是 https://whoiscx.delishahk.com ，直接在网页里输入域名或者 URL 就能查！”

芽衣：“那如果是像琪亚娜这样的‘高级玩家’，是不是可以直接调用 API 接口？”

琪亚娜：(凑近芽衣，仰起头求夸奖) “芽衣真聪明！API 格式是 https://whoiscx.delishahk.com/api/?whois=查询的域名或URL ！不过博主说，返回的数据太长了，他才不贴在博客里呢，想看具体数据得自己去介绍页看，嘿嘿。”

芽衣：“那这个 RDAP 方案，支持所有的域名后缀吗？”

琪亚娜：“(翻看平板，认真地念) 目前 RDAP 已经支持 1000+ 的域名后缀啦！博主在 GitHub 上翻到了 jakejarvis 大佬的 rdapper 项目，原本支持 RDAP 和 WHOIS 双支持，但在无服务器部署下只支持 RDAP。
还有一些小众域名和国家级域名（ccTLD）暂时不支持，比如 .de（德国）、.cn（中国）、.us（美国）、.jp（日本）、.it（意大利）、.es（西班牙）、.mx（墨西哥）。不过博主说可以期待后续更新，希望能支持所有域名！”

芽衣：“能支持一千多种后缀，已经能解决绝大多数问题了。这位博主愿意花时间搭建公益 API 为大家提供方便，确实很用心呢。琪亚娜能发现这么有用的工具，德丽莎一定会夸奖你的。”

琪亚娜：(顺势抱住芽衣的腰，把脸埋在芽衣怀里蹭了蹭) “嘿嘿，比起德丽莎的夸奖，本小姐更想要芽衣的奖励！比如……再给我添一碗饭？或者，今晚可以抱着芽衣睡？”

芽衣：(脸颊微红，轻轻拍了拍琪亚娜的后背) “饭可以添，但是睡觉要乖乖的，不许半夜抢被子哦。快去洗手吧，菜要凉了。”

琪亚娜：“好耶！芽衣做的饭最棒了！本小姐开动了！”

(夕阳的余晖透过休伯利安号的舷窗洒在两人身上，休息室里充满了饭菜的香气与温馨日常的欢笑。)
